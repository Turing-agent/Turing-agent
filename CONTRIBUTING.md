# Contributing to Turing-agent

Thank you for considering contributing to Turing-agent! 🎉

## Reporting Bugs
1. Click **New issue** → select **Bug report**.
2. Provide clear reproduction steps, logs, and screenshots.

## Feature Requests & Enhancements
- Use the **Feature request** or **Enhancement** template.
- Detail the problem motivation and suggested solution.

## Pull Request Guidelines
1. Fork the repo and create a feature branch (`git checkout -b feat/your-feature`).
2. Keep changes focused and surgical.
3. Submit a PR and link the related issue (`Closes #<issue_number>`).

Happy hacking! 🐟
